Network

In Offline mode, Ask AI still works with your downloaded model, attached files and pages you already have open. Web search, image search, websites and model downloads are blocked.

Only add a local service you trust. Some local services (for example a search engine like SearXNG, a proxy or an AI server) forward what you send to the internet, and Offline mode can't see past them.

    Startup

    Sovereign restores window and tab URLs only. It does not restore unsaved form text.

    Search Backend

    Search queries go to this local or private-network SearXNG endpoint. Upstream search engines may still receive queries from SearXNG.

    Local Model

    Enabled by default. Setup downloads the configured model files in the background and uses disk space; answer generation runs locally after setup. If setup is interrupted, retrying reuses cached files when WebLLM can, otherwise it starts the remaining setup again.

    The current model remains available. Selecting a larger model does not download it until setup starts.

    When disabled, new Ask AI chats stay in memory for the current tab only. Turning it off offers to delete chats already saved; Clear history in Ask AI deletes them at any time. Deleted chats are removed from Sovereign’s storage. Chromium may keep fragments in its internal files until it cleans them up; exported copies and system backups are not affected.

    Runtime
    Answer generation and summaries run locally after setup. Sovereign does not use a cloud AI fallback.

    Observed bottleneck so far: the small local model sometimes ignores citation instructions or emits invalid citation numbers. Sovereign validates the output and falls back to source excerpts when needed. A later model upgrade should be evaluated with measured citation reliability, latency, and memory use before changing models.
